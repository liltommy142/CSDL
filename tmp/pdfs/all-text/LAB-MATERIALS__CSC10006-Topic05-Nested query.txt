2 Detailed Instructions 
2.1 Introduction to Nested Queries
Definition: A nested query (subquery) is a query that contains another query
within its statement.
Syntax:
SELECT A
FROM X
WHERE … ( SELECT B  FROM  Y WHERE …)  …
Based on the characteristics of subqueries, nested queries can be classified into
two main types:
Hierarchical Nested Queries: A hierarchical nested query is a query in which 
the subquery is independent of the outer (parent) query
SELECT A
FROM X
WHERE ... (SELECT B, C FROM Y) ...

In  this  example,  the  subquery  SELECT  B,  C  FROM  Y  does  not reference  any
component of the outer query. Therefore, it is classified as a  hierarchical nested
query.
Correlated Subqueries: A correlated subquery is a query in which the subquery 
depends on the outer query
SELECT A
FROM X
WHERE ... (SELECT B, C FROM Y WHERE B = X.A) ...
In this example, the subquery SELECT B, C FROM Y WHERE B = X.A references a
column from the outer query through the comparison B = X.A. Therefore, this is a
correlated subquery.
2.2 Placement of Subqueries in the Outer Query: 
A subquery can appear in different parts of the outer query. Common positions 
include the SELECT, FROM, and most commonly, the WHERE clause.
2.2.1 Subquery in the SELECT Clause
The result of the subquery is treated as a single attribute value.
Example 1: For each department, retrieve the department name and the number of 
teachers in that department.
SELECT BM.TENBM, ( SELECT COUNT(*) 
FROM GIAOVIEN GV 
WHERE GV.MABM = BM.MABM)
FROM BOMON BM
2.2.2 Subquery in the FROM Clause
The result of the subquery is treated as a derived table, which can be queried like a 
regular table.
Example 2: Retrieve the full name and salary of teachers in the HTTT department

The result of the subquery is used as part of a conditional expression

with MAGV = '001'

FROM  GIAOVIEN

FROM GIAOVIEN

2.3 Hierarchical Nested Queries with the IN Operator
The IN operator is used to check whether a value belongs to a given set of values.
This set can be the result of a subquery or an explicitly specified list of values (see 
Topic 03 – Basic Queries).
Syntax: <attribute> IN <set>
<attribute> IN (     SELECT ...
FROM ...
WHERE ...)
Or: 
<attribute> IN (value1, value2, ..., valueN)
The condition evaluates to TRUE if the attribute value appears in the set; otherwise, 
it evaluates to FALSE.

2.4 Hierarchical Nested Queries with the ALL Operator
The ALL operator is used together with comparison operators such as
>, <, >=, <=, !=, etc.
Syntax: <attribute> [> | < | >= | <= | !=] ALL <set>
This condition evaluates to TRUE if the attribute value satisfies the comparison with
all elements in the set
Example 6: Retrieve teachers who have the lowest salary.
SELECT *
FROM GIAOVIEN
WHERE LUONG <= ALL (SELECT LUONG FROM GIAOVIEN)
Example 7 : Retrieve teachers whose salary is higher than all teachers in the HTTT
department.
SELECT *
FROM GIAOVIEN
WHERE LUONG >=ALL(SELECT LUONG 
                                               FROM GIAOVIEN 
                                   WHERE MABM= ‘HTTT’)

2.5 Hierarchical Nested Queries with ANY and SOME
The syntax for using ANY and SOME is similar to that of ALL.
 ALL: the condition must be satisfied for all values in the set.
 ANY / SOME: the condition must be satisfied for at least one value in the set.
Example 10: Retrieve the names of teachers who participate in at least one project 
(using = ANY instead of IN).
SELECT HOTEN
FROM GIAOVIEN
WHERE  MAGV = ANY (SELECT MAGV
FROM THAMGIADT)

2.6 Correlated Subqueries with EXISTS
EXISTS is commonly used in conditional expressions
… EXISTS ( SELECT …
FROM …
WHERE … )
 The EXISTS condition evaluates to TRUE if the subquery returns one or more
rows.
 If the subquery returns no rows, the condition evaluates to FALSE
 EXISTS is most commonly used in correlated subqueries.
 Unlike IN, EXISTS only checks for the existence of rows, not actual values, and
is often more efficient for large datasets
Example 11: Retrieve teachers who participate in at least one project.
SELECT HOTEN
FROM GIAOVIEN GV
WHERE EXISTS ( SELECT * 
FROM THAMGIADT TG
WHERE TG.MAGV = GV.MAGV)
