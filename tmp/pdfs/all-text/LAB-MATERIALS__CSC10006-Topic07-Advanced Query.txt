2.2 Joining
Consider the following 2 data tables:
SINHVIEN LOP
Requirement: Show the number of students in each class
2.2.1 Inner joins  
Inner join between 2 tables A and B is a table C = {tuples where each tuple is a combination of 
tuples in A with tuples in B such that the join condition is satisfied}
To Inner join between SINHVIEN and LOP :
-- Using JOIN:
SELECT * 
FROM SINHVIEN AS SV JOIN LOP AS L ON SV.MALOP = L.MALOP
-- Or using join condition in WHERE clause:
SELECT *
FROM SINHVIEN SV, LOP L
WHERE SV.MALOP = L.MALOP

To Calculate number of student in each class :
SELECT L.MALOP, L.TENLOP, COUNT(*) AS SISO
FROM SINHVIEN AS SV JOIN LOP AS L ON SV.MALOP = L.MALOP
GROUP BY L.MALOP, L.TENLOP

10C was lost after the inner join. Therefore, with inner join, tuples that do not satisfy the join
condition will be removed. If you want it to appear → Use outer join.
2.2.2 Right (Outer) joins  
Right Outer  join between 2 tables A and B is a table C = {tuples where each tuple is a
combination  of  tuples  in  A  with  tuples  in  B  such  that  the  join  condition  is  satisfied}  +
{remaining tuples in B that do not satisfy the join condition with any tuple in A}
To Right (Outer) Joins between SINHVIEN and LOP :
SELECT * 
FROM SINHVIEN as SV RIGHT JOIN LOP as L ON SV.MALOP = L.MALOP

2.2.3 Left (Outer) joins  
Left (Outer) join between 2 tables A and B is a table C = {tuples where each tuple is a 
combination of tuples in A with tuples in B such that the join condition is satisfied} + 
{remaining tuples in A that do not satisfy the join condition with any tuple in B}
2.2.4 Full (Outer) joins  
Full Outer join between 2 tables A and B is a table C = 
{tuples where each tuple is a combination of tuples in A with tuples in B such that the join
condition is satisfied} + 
{remaining tuples in A that do not satisfy the join condition with any tuple in B} + 
{remaining tuples in B that do not satisfy the join condition with any tuple in A}

2.5.3 Using GROUPING:  
Syntax: GROUPING (<attribute name>)
Grouping is used to check whether the value of an attribute in the query result is from actual data
or generated by the query
Explanation with the above example:
- If Grouping value of attribute name (itemname) is 1 → NULL value appears due to CUBE 
clause → meaning any name (generated by the query)
- If Grouping value of attribute name (itemname) is 0 → NULL value means the item's name is 
NULL (from actual data: itemname is NULL).
