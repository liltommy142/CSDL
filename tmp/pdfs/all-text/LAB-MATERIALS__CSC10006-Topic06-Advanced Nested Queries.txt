Methods:
 Use EXCEPT operator
 Nested query with NOT EXISTS or NOT IN
Example 2: Find teachers who do not participate in any project.
Observation: 
Teachers not participating in projects = All teachers – Teachers participating in projects.
Using EXCEPT:
-- Simple: Only shows MAGV information
SELECT MAGV 
FROM GIAOVIEN GV
EXCEPT 
SELECT MAGV 
FROM THAMGIADT TG
-- Complex: Shows MAGV and HOTEN information
SELECT MAGV, HOTEN 
FROM GIAOVIEN GV
EXCEPT 
SELECT GV.MAGV, GV.HOTEN 
FROM THAMGIADT TG, GIAOVIEN GV 
WHERE TG.MAGV = GV.MAGV

2.2.1 Using NOT EXISTS ... EXCEPT  
Formula:
SELECT R1.A, R1.B, R1.C
FROM R R1
WHERE NOT EXISTS (
( SELECT S.D, S.E FROM S)
 EXCEPT 
 ( SELECT R2.D, R2.E 
 FROM R R2
 WHERE R1.A=R2.A AND R1.B=R2.B  AND R1.C=R2.C )
